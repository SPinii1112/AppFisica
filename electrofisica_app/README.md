# ⚡ ElectroLab 3D — Simulador Interactivo de Electrostática

Aplicación web interactiva de Física Electrostática desarrollada en Python con Streamlit.

## 🔗 Demo en vivo
[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://tu-usuario.streamlit.app)

## ✨ Funcionalidades
- **🧲 Ley de Coulomb** con Punto de Campo Cero (E=0) animado
- **📐 Presets modificables** de 3 y 4 cargas (triángulo, cuadrado, anillo)
- **🔍 Evaluador de Campo Eléctrico** en cualquier punto P(X,Y)
- **🚀 Simulación de movimiento** con solver RK4
- **🎓 Modo Profe**: Glosario de 20+ definiciones + Juego de 20 Escalones con 60 preguntas únicas

## 🚀 Cómo ejecutar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📦 Tecnologías
- Python 3.11+
- Streamlit
- Plotly
- NumPy
